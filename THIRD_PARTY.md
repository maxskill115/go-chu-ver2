# Third-party assets

## Twemoji

Phase 3 dùng một số hình SVG từ dự án **Twemoji** để minh họa prompt trong chế độ Đơn giản.

- Project: `jdecked/twemoji`
- Phiên bản asset được ghim: `v17.0.3`
- CDN: jsDelivr
- Graphics license: Creative Commons Attribution 4.0 International (CC BY 4.0)
- Code license của Twemoji: MIT

Các file hình không được copy trực tiếp vào repo ở Phase 3; `visual-data.js` tham chiếu tới SVG được ghim phiên bản trên CDN. Nếu CDN không tải được, giao diện tự fallback sang emoji Unicode tương ứng.
